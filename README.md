# CookWise (static prototype)

The first version of CookWise, a recipe-sharing website, built with plain HTML, CSS and JavaScript.

Open `Homepage.html` in a browser to view it.

| Page | Purpose |
| --- | --- |
| `Homepage.html` | Landing page with the four recipe categories |
| `sweets.html`, `spicy.html`, `maindishes.html`, `appetisers.html` | Recipes in each category, rendered by `cat.js` |
| `cat.html` | All recipes |
| `Loginpage.html`, `Registration.html` | Login and sign-up forms (front end only) |

This prototype is being rebuilt as a Django web application in the
[cookwise-django](https://github.com/MI-AN-O/cookwise-django) repository.
